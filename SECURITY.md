# Security Policy

## Supported Version

Security and privacy fixes are applied to the latest version on the `main` branch.

## Reporting a Vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner privately through an approved channel.

Include:

- A clear description of the issue
- Steps to reproduce it
- Browser and operating system
- Potential impact
- A suggested mitigation, if available

Do not include real meeting notes, transcripts, credentials, personal information, or confidential organisational data.

## Data Handling

The application is designed to run locally in the browser without a backend, account, analytics service, or external API. Any change that introduces data transmission, browser storage, external scripts, or third-party services must be clearly documented and reviewed before release.
