# Contributing

Thank you for helping improve the Minutes Prompt Generator.

## Before You Start

Please keep the project:

- Standalone and easy to share
- Free from server-side dependencies
- Free from unnecessary data collection
- Clear for busy users
- Accessible by keyboard
- High contrast and responsive

## Reporting an Issue

When opening an issue, include:

- A short, descriptive title
- Browser and device used
- Steps to reproduce the problem
- Expected result
- Actual result
- Screenshot, if it does not contain confidential information

Do not include real meeting notes, transcripts, personal information, or confidential project data.

## Suggesting an Enhancement

Explain:

1. The user problem
2. The proposed change
3. Why it improves clarity, accessibility, privacy, or accuracy
4. Any possible drawbacks

## Pull Requests

1. Create a branch from `main`.
2. Make a focused change.
3. Test the tool locally in at least one desktop and one mobile-sized browser window.
4. Confirm required-field validation, prompt generation, copy feedback, and download feedback.
5. Update `CHANGELOG.md` when appropriate.
6. Open a pull request with a clear summary and test notes.

By contributing, you agree that your contribution will be licensed under the repository's MIT License.
